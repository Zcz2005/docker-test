区块链使用案例

本案例以「网络直播侵权取证」为场景，展示区块链在电子证据领域的典型应用： 解决证据易篡改、溯源难、多方互信难三大痛点。

📋 案例背景：直播售假侵权取证

权利人委托公证处对某抖音主播销售假冒化妆品的直播行为进行取证。系统自动录制直播视频， 计算 SHA-256 哈希后上传至天翼云对象存储，同时将关键元数据写入区块链，形成完整的证据链。

🔴

痛点一：证据易篡改

传统电子证据以文件形式存储，修改后难以察觉。区块链通过哈希上链，任何文件变动都会导致哈希不匹配，篡改一目了然。

🟡

痛点二：溯源链条断裂

证据从采集到出庭经历多环节流转。链上记录每次保管转移和公证操作，形成不可断裂的时间线。

🟢

痛点三：多方互信困难

当事人、公证处、法院对证据真实性各执一词。区块链的分布式共识和 PoW 机制提供技术层面的信任基础。

交易类型 (Transaction Types)

evidence_submit 证据提交 — 将文件哈希和案件元数据上链

custody_transfer 保管转移 — 记录证据保管权变更

notary_seal 公证封印 — 公证处出具保管证明

genesis 创世交易 — 链初始化

共识机制

采用工作量证明 (Proof of Work)，要求区块哈希以 N 个零开头（当前难度=4）。 打包时自动挖矿，确保写入成本，防止垃圾交易攻击。

API 文档

RESTful API 接口，可与取证系统、公证处后台对接。

方法路径说明
GET/api/chain/summary链概览（高度、证据数、有效性）
GET/api/chain/blocks获取所有区块
GET/api/chain/blocks/{index}获取指定区块

POST/api/chain/mine挖矿打包待处理交易
