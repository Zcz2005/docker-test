# 绿链溯源 GreenChain

基于区块链的农产品全链路溯源平台 — 详细使用案例网站。

## 案例简介

**绿链溯源（GreenChain）** 是一个面向农产品行业的联盟链溯源平台使用案例，以「有机番茄」为例，完整展示区块链如何在供应链中实现从田间到餐桌的全链路追溯。

### 核心特性

- **9 大章节**：案例概述、痛点分析、解决方案、技术架构、业务流程、智能合约、交互演示、效益分析、FAQ
- **联盟链架构**：基于 Hyperledger Fabric 2.5，PBFT 共识，4 组织 7 节点
- **智能合约示例**：Go Chaincode 完整代码（批次管理、溯源记录、质检、权限控制）
- **交互演示**：可操作的区块链模拟器，亲手体验 6 环节上链过程
- **消费者查询**：模拟扫码溯源，验证链上数据完整性

### 参与角色

农户/合作社、加工厂、质检机构、物流公司、零售商、监管部门、消费者、平台运营方

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

开发服务器默认运行在 http://localhost:5173

## 案例亮点

1. **不可篡改**：联盟链共识机制保证溯源数据写入后无法修改
2. **秒级追溯**：输入批次号 3 秒内定位全链路信息
3. **IoT 集成**：温湿度传感器数据自动上链，异常自动预警
4. **司法认可**：符合国密标准的区块链存证，具备法律效力
5. **成本可控**：链上哈希 + 链下存储混合架构，TPS 500+
